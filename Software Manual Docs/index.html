CHAPTER 01

01Introduction & Overview

Sigma Controls IntelliScan is a professional windows based desktop application for industrial data logging using the RS-485 Modbus RTU protocol. It connects to up to 8 Modbus slave devices on a single RS-485 bus, each supplying up to 24 channels (CH01-CH24) of sensor data.

What the Software Does

LIVE MONITORING
Reads Modbus holding registers in real-time. 24 LCD-style displays per slave updated per second.
DATA LOGGING
Store data values to CSV at a user-configured Log Time interval.
LIVE GRAPHING
Time-series graph for all 24 channels with unique colours, dual legends & auto-scaling time axis.
PDF REPORTS
Professional PDFs with custom company letterhead and remarks text. Graph PDF gives the plot ≥70% of page height.

Key Specifications

CHAPTER 03

03Login Screen

Every launch first runs a silent license check. Once that check passes, the Login window appears. Enter your credentials to access the main interface.

Fig 3.1 - Login window with User ID and Password fields

Login Steps

  1. Launch the .exe — License check runs first (silent). If it passes, the login window appears.
  2. Enter User ID — Click the field and type your username.
  3. Enter Password — Characters appear as dots for security.
  4. Click Submit or press Ctrl+S — Credentials checked against credentials.json and MAC address.

04Main Interface Overview

The IntelliScan main interface provides a centralized workspace for real-time telemetry monitoring, communication configuration, data visualization, and channel management.

Fig 4.1 - Main interface showing all controls, slave selector, and tab widget

Control Areas

ControlFunction
COM Port DropdownSelect which COM port the RS-485 adapter is on

Tab Structure

TAB 1 - DATA
24 LCD number displays. Live scaled values for selected slave.
TAB 2 - CSV
Full scrollable CSV table. Every row since session start.
TAB 3 - GRAPH
Live time-series graph. All 24 channels in unique colours. Dual legend panels.
TAB 4 - ADV. SETTINGS
CSV selector, letterhead, remarks text, date/time filter, Submit (filtered graph), Print (generate PDFs).

Comms Watchdog LED

A small status dot + label sits in the top-right corner of the tab bar (above TAB 1-4), always visible regardless of which tab is open: Idle (grey, before Start is pressed), Connected (green), Reconnecting... (amber, while the watchdog is retrying a dropped Modbus link), and Lost (red).

05Communication Settings

Configure serial parameters to exactly match your Modbus slave devices. Any mismatch causes complete communication failure.

Fig 5.1 - Settings area showing COM port, baud rate, parity, data bits, stop bits, slave selector
SettingOptionsDescription
COM PortCOM1 - COM256Windows COM port of your USB-RS485 adapter. Check Device Manager.
Baud Rate9600 / 19200 / 115200Must match device. Most industrial devices use 9600.
ParityN / E / ONone / Even / Odd. N is Modbus RTU standard.
Data Bits7 / 88 is Modbus RTU standard.
Stop Bits1 / 21 is Modbus RTU standard.
Slave1 - 8Which slave to display. Only enabled slaves are valid selections.
All settings auto-save to config.json on clicking Save. Configure once per machine.
COM Port, Baud, Parity, Data Bits, Stop Bits, and ID Settings button are all disabled while communication is running. Press Stop first.

Full scrollable table of today's complete log for the selected slave. All rows since midnight. New rows appear at the bottom as data is logged. For previous days use Advanced Settings to load an older CSV.

Prepare and generate printed PDF reports from logged data.Three steps: load Excel(.csv) + set letterhead & header(remarks), set date/time filter range, then generate the filtered PDFs of data table & graph.

Fig 10.1 - Advanced Settings tab with CSV selector, letterhead, header text, date/time filter

Channel Selection Dialog

Before the data table & graph opens, a Channel Selection dialog lists every channel found in the Excel(.csv) (e.g. CH01-CH24), each with a checkbox, defaulting to all shown. Use Select All / Select None to toggle everything at once, then tick individual channels as needed and press Show Graph and Table. This selection is independent of the live logging CH01Check-CH24Check checkboxes on the main screen — filtering channels here never affects an active logging session.

Fig 10.1 - Channel Selection dialog with Select All / Select None and per-channel checkboxes

Graph View Window

The featured graph window displays the selected channels' data over the filtered date range.

Fig 10.2 - Featured Graph window: green START marker, red STOP marker, hover tooltips, pale-green plot area

Data Table Window

Alongside the Featured Graph, a separate "Data Table" window opens showing the same filtered date range as a scrollable table (Date, Time, and every selected channel, labelled CH01, CH02, etc.), with a file name / channel count / row count summary above the table.

Fig 10.3 - Data Table window: File / Channels shown / Rows summary, scrollable table with CH01-style headers

CHAPTER 12

12CSV Replay Mode

CSV Replay Mode lets you load a historical CSV file and play it back through the live UI — LCD displays, graph, and data table — as if the data were being received live in real-time. Useful for reviewing past sessions and demos.

How to Use CSV Replay

  1. Press Ctrl+R — Opens a file dialog. Select any previously logged CSV file (e.g., 11-05-2026_ID_1.csv).
  2. Replay starts automatically — The software reads rows from the CSV one by one and feeds them into the UI at the configured speed.
  3. Set replay speed — Use keyboard shortcuts to control playback speed (see Keyboard Shortcuts chapter).
  4. Watch live UI update — LCD displays, graph, and data table all update as if data is arriving live.
Replay mode feeds data through the same display pipeline as live communication, so all graph colours, OPE detection, and channel enable/disable states behave identically.
Pressing Start while a replay is running stops the replay completely (timer, graph, and table) and begins live logging.

13Errors & Troubleshooting

Error / SymptomCauseSolution
"Invalid credentials"Wrong User ID or Password.Re-enter correct credentials.
COM port not found on startupAdapter unplugged or driver missing.Check USB, Device Manager, reselect port.
LCD shows OPE blinkingRaw register > 15000. Sensor disconnected.Check wiring, terminals, Modbus address.
Graph shows "No Response"Slave not responding to Modbus poll.Check power, A/B polarity, baud rate, slave ID.
"Div Factor is empty"Slave enabled but Div Factor left blank.Enter a number (e.g., 10) for all enabled slaves.
PDFs missing graphPrint clicked before closing Submit graph.Submit, close graph, then Print.
